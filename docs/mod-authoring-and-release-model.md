# 地块 Mod 制作与版本发布

## 作者能做什么

地块 Mod 是经结构校验的 JSON 数据，不是能在客户端执行的插件代码。一个 Mod 只对应一个地块：JSON 只写一个 `definition.terrain` 对象，地块 ID 从 Mod ID 派生，显示名称沿用 Mod 名称，设置目标也不重复填写地块 ID。该地块可选择游戏提供的能力，例如可占领、供电、回合收益、离开留兵和反击限制，并可添加整数、开关或选项类的房间设置。地块收益除常用预设外，还能填写自定义条件表达式，用 `all`、`any`、`not` 组合地块能力、单位通电、队伍或单位标记等内置条件。作者更新 Mod 时，地块 ID 由 Mod ID 固定派生；已发布设置会在可视化模式中回填并保护，服务端会拒绝删除或重定向旧设置、缩小旧整数范围或移除旧选项。

可视化创作页可设置该地块的底色、底部图层和一个可选顶部图层，并实时预览大小、透明度和位置。顶部图层可设为仅在格子有单位占领时显示；完整 JSON 使用单数 `overlay` 对象定义此图层，并可设 `whenOccupied: true`，单位离开后图层立即隐藏。底部外观必须明确选择纯色、有效图片或“透明底”（棋盘背景透出，效果类似虚无地块）；没有顶部装饰层完全合法。整个 Mod 的图片会转为 WebP，单张最多 128 KiB、总计最多 4 张不同资源；图片只影响渲染，不参与规则计算，但会进入版本内容指纹。完整 JSON 与可视化模式可以双向切换；已有设置、能力、图片及规则会从当前版本填回表单。地图、准备房间、工坊地图预览和地图编辑器使用同一份地块视觉定义。

进阶作者可在完整 JSON 模式中组合有限空间查询、事件、条件和效果，例如路径匹配、兵力增减、获得点数、失活和单位标记。工坊也提供区域失活快捷生成：把当前编辑地形作为范围起点，指定队伍、外围圈数、进入/离开和是否只在跨越边界时触发；生成结果仍可在空间规则 JSON 中继续改成任意受支持路径表达式。核心据点的一圈敌方失活也使用相同的空间模式与规则，不是可以绑定到任意地块的普通地形能力。

项目自带的示例 Mod 包含“生息林”（占领后按可配置点数在回合开始产出）和“边境屏障”（范围 1～3 圈可调，并能独立选择进入或离开边界时失活），可在地图编辑器里直接选用。它们是可运行的规则样本，也用来回归测试 Mod 设置、空间范围与规则触发；不依赖上传脚本。

也可以声明 `mod/<mod-slug>/<name>` 自定义能力，让规则通过标记识别地块；若要调整能力参数，可将其暴露成整数、开关或选项设置，再让规则按设置值判断条件，或用整数设置决定点数/兵力变化。自定义能力的任意 JSON 参数目前不是规则表达式，不能直接读取，也不会执行自定义代码。规则由共享的 `game-core` 解释，不执行上传脚本。边界很明确：作者能组合现有原语，但不能声明内核不存在的新效果或新计算；要支持新的效果原语，必须先扩展并测试共享规则解释器，再让 Mod 使用。

规则类型以 `game-core` 为唯一来源，Workshop Schema 复用同一组定义，避免作者端漏掉引擎已经支持的目标限制（例如只选触发玩家或只选通电单位）。一条规则里的效果按声明顺序生效；若某种效果可能改变空间目标成员（移除单位、改标记），下一个效果会重新解析目标，否则会复用当前选择，减少重复的整盘空间查询。

## 不可变发布与地图绑定

同一 Mod ID 的更新必须由原作者以更高的 SemVer 发布。更新会追加一条新发布记录，不会修改旧记录；同一 ID 只能通过“发布新版本”继续维护。地块 ID 固定从 Mod ID 派生，不能单独重命名；为保证已发布地图可以随 Mod 更新继续加载，更新也不能删除或重定向旧参数、缩小整数范围或删除选项。暂不支持破坏性更新；需要移除旧内容时，应先提供地图迁移能力。版本历史暂限每个 Mod 128 个发布版本、工坊总计 1,024 个版本记录，并受 128 MiB 服务端存储上限约束。

版本指纹使用 SDK 中唯一的 `modContentIdentity()` 投影和规范 JSON SHA-256，包含规则、能力、设置、地块定义及美术资源。地图只记录所需的 Mod ID，不保存版本号或内容指纹：

- 单机地图始终使用本机当前活动版本；Mod 自动更新后，依赖它的地图自然使用新版本，无须逐张保存或重绑。
- 在线房间以房主当前活动版本为准。房间状态独立广播版本与内容指纹，参战玩家必须取得同一版本后才能准备；开始对局时该版本集被冻结，不能在对局中途替换规则。
- 其他玩家缺少房主版本时，可从工坊缓存该不可变发布版本，不会因此降级其全局订阅版本。房主在准备阶段更换活动版本后，房间会重新校验并要求玩家再次准备。
- 老地图里原有的 `requiredTerrainModLocks` 字段会被忽略，并在地图规范化/分享时移除，不会阻止地图跟随当前 Mod。
- 取消订阅只停止今后自动更新，不会卸载本机当前版本。

订阅更新会在打开创意工坊或进入战斗大厅/准备房间时检查；准备阶段若检测到新版本，会先取消本机准备并在下载完成前阻止再次准备，避免开局时新旧美术资源不一致。更新仍不会在进行中的对局替换规则。普通首页不建立工坊连接。
