### A. 棋盘与无界面规则

- [x] 旧版偶数行错列六边形邻接、单格单棋子、山地/虚无不可驻兵；可行动目标按真实规则计算。
- [x] 按座位依次行动，队友仅共享胜负；友伤是房间设置。行动、加点两阶段；可主动结束并保留剩余点数；无合法行动/点数耗尽可自动推进。
- [x] 供电由同一玩家占据据点的连续导电棋子派生；断电立即减 1，1 点阵亡；据点周围敌军失活但自身格、空据点、友方据点不触发。
- [x] 通电 1 点不能行动；回合开始计算收入。游兵行动减 1 最低留 1，1 点行动后失活；游兵离开海洋失活。攻击占领时由目标地形的进入触发判断占领后的供电：仍未通电才失活；敌方据点封锁先执行，即使刚通电也失活。
- [x] 油田作为独立地块 Mod：不导电，离开需留本回合失活的 1 点游兵；收益可由地图和房主配置。
- [x] 攻击、攻击范围、反击、反击次数为独立能力；远程攻击可不进入目标格；胜负由地图选择模块（最后一队、失去所有据点等）。
- [x] 棋谱是 `[行, 列, 点击次数]`；无意义选中/取消/自动续选不写入，同格连续加点合并；续选坐标与目标坐标分离。
- [x] 规则内核不依赖 Vue、DOM 和网络，Node/浏览器/将来 AI 可复用。
- [ ] 旧版战斗细节的逐条核对和最终规则确认；现有近战公式仍是原型规则。
- [ ] 棋谱的服务端持久化、严格重放与 AI 训练数据导出。
