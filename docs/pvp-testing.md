# PvP 与 Mod 联调清单

## 当前可测范围

- 单浏览器本地预测：已可测移动、攻击、供电、据点封锁、油田收益和阶段切换。
- 油田 Mod：演示地图已安装 `mod-oil-field`，两个油田位于行列 `[2,6]`、`[6,1]`，视觉上使用棕色底和金色六边形边框。
- 无界面规则：`game-core` 的 `getLegalIntents`/`applyIntent` 可以给服务端和 AI 训练程序复用。

## 真正双人 PvP 还缺什么

1. 在 `apps/server` 增加一个 Colyseus Room：房间保存权威 `GameState`，按座位绑定玩家，并把客户端意图交给 `validateIntent`。
2. 定义连接协议：加入房间、分配席位、提交 `commandId`/意图、广播新状态和拒绝原因、断线重连。
3. 房间创建时加载同一份内容目录：核心目录、地图选择的 Mod catalog、单位目录和胜负条件目录必须与前端一致。
4. 启动两个浏览器客户端（或一个浏览器的两个标签）连接同一房间，验证一个客户端的本地预测最终被服务端状态确认。

## 建议的第一轮验收

- 两个玩家依次行动，非当前玩家提交意图会被服务端拒绝。
- 客户端篡改目标格、旧 `sequence` 或伪造 Mod 地形时，服务端拒绝并返回最新状态。
- 地图装配 `oilFieldTerrainCatalog` 时，油田收益和离开留守兵规则在前后端一致；不装配时，核心地图完全不认识 `mod/oil-field`。
- 断线重连后以服务端快照恢复选择状态，不能依赖浏览器内存中的棋谱或 Pixi 对象。
