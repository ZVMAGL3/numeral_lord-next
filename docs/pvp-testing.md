# PvP 与 Mod 联调清单

## 当前可测范围

- 单浏览器本地预测：已可测移动、攻击、供电、据点封锁、油田收益和阶段切换。
- 油田 Mod：演示地图已安装 `mod-oil-field`，两个油田位于行列 `[2,6]`、`[6,1]`，视觉上使用棕色底和金色六边形边框。
- 无界面规则：`game-core` 的 `getLegalIntents`/`applyIntent` 可以给服务端和 AI 训练程序复用。

## 当前双人 PvP 实现

`apps/server` 已提供一个薄的 Colyseus `pvp` 房间：后端只负责账户/席位、房间发现、连接/断线重连和消息广播，不保存或重放对局规则。房主客户端拥有本地 `GameState`，执行 `game-core` 后广播 `host-snapshot`；其他客户端把 `player-intent` 发给房主并套用快照。发生冲突时，以房主快照为准。

启动服务端：

```powershell
corepack pnpm --filter @numeral-lord/server start
```

打开两个 `http://127.0.0.1:5173/` 标签即可自动加入同一个房间。要连接远程中继，在页面地址后加 `?relay=ws://服务器地址:2567`（HTTPS 页面使用 `wss://`）。页面顶栏会显示房间号、席位和房主状态。

房间创建时仍需要让所有客户端加载相同的地图、核心目录和 Mod catalog；中继不会替客户端安装 Mod，也不会替客户端执行规则。

## 建议的第一轮验收

- 两个玩家加入同一房间后，房主可以看到非房主的命令并广播结果；冲突时非房主最终回到房主快照。
- 房主离开后，房间自动把下一位客户端提升为房主并继续广播。
- 地图装配 `oilFieldTerrainCatalog` 时，油田收益和离开留守兵规则在前后端一致；不装配时，核心地图完全不认识 `mod/oil-field`。
- 断线重连由 Colyseus 房间层处理；当前版本的对局快照以房主内存为准，持久化/战绩服务留待后续阶段。
